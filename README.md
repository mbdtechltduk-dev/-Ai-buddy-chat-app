## Overview

AIBuddy Chat is a cross-platform Flutter application
designed around personalized AI companion experiences.

The published app features a dark-themed interface,
companion personalization, conversational messaging,
reminders and wellness-focused navigation.

## Key Features

### AI Companion Experience
- Personalized companion chat interface

- Conversation-focused mobile interface
